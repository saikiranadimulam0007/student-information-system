# 🎓 Student Information System

A simple **Python console application** that collects student details, calculates total and average marks, and displays the student's information in a formatted output.

This project is ideal for beginners learning Python basics such as variables, user input, arithmetic operations, and formatted printing.

---

## 🚀 Features

- 👤 Accepts student details
- 🎓 Stores roll number and department
- 📚 Accepts marks for three subjects
- ➕ Calculates total marks
- 📊 Calculates average marks
- 🖥️ Displays all student information
- 🐍 Beginner-friendly Python project
